# ADR Engine Studios

Welcome to **ADR Engine Studios**!

This is where all things related to **ADR Engine** go.

ADR Engine is currently a **small, performance-focused FNF engine** designed mainly for regular gameplay and good performance.

It may eventually become powerful enough to beat **H-Slice**, but for now, ADR Engine is focused on being a lightweight and reliable engine for normal gameplay.

### Current Focus

* ⚡ Performance
* 🎮 Regular gameplay
* 🚀 Fast and lightweight
* 🛠️ Continuous optimization

**ADR Engine is still in development, so expect more improvements and features over time!**
